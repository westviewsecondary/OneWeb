- Banner: a smaller information strip across the website.
- PDFs: upload newsletters, letters, policies and transport documents.
  Optional letter text preserves paragraphs alongside the original PDF.

DESIGN AND CONTENT
A new rounded OneWeb design, using information from the existing Westview
website. Static information is in pages.json; update that file for changes
